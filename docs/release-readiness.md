# Public release blockers

The following owner-supplied inputs are required before release:

- Replace `OWNER` in manifest URLs with the real public GitHub owner.
- Add the real GitHub code owner to `manifest.json`.
- Replace the non-license placeholder with the approved license.
- Add official Domee brand assets under `custom_components/domee/brand/`.
- Create the public repository and an immutable tag or commit for backend
  compatibility validation.

No placeholder metadata may remain in a release candidate.
